# 检索结果与评分解释

本文档说明 LongPsychAgent 返回的候选字段、排序含义和使用边界。

## 1. 常见返回结构

工具成功时通常返回包含 `status="ok"` 和 `data` 的对象。发生业务错误时可能返回 `status="error"` 和诊断信息。

检索结果中的常见字段如下：

| 字段 | 含义 | 使用说明 |
|---|---|---|
| `response_uid` | 候选回复的唯一标识 | 用于标识语料中的候选回复 |
| `response_text` | 候选回复原文 | 展示时保留原文 |
| `rank` | 当前结果列表中的最终名次 | 表示所选检索模式返回的排序位置 |
| `retrieval_score` | 第一阶段检索分数 | QR-Future 模式下对应 Dense 第一阶段相似度 |
| `qr_future_score` | QR-Future 原始排序分数 | 仅在 QR-Future 结果中出现；不是概率 |
| `candidate_rank` | QR-Future 重排前的候选名次 | 对应 Dense 第一阶段候选排序位置 |
| `faiss_row` | FAISS 内部行号 | 工程调试标识，不是用户可解释的语义指标 |

实际字段以工具本次返回为准；某个模式未提供的字段不应自行补造。

## 2. QR-Future 排序过程

QR-Future 在线检索包含两个阶段：

1. Dense 第一阶段召回候选。
2. 五折 QR-Future FULL 排序模型对候选重排。

在 QR-Future 结果中：

- `candidate_rank` 表示候选在 Dense 第一阶段中的原始位置。
- `rank` 表示 QR-Future 重排后返回列表中的最终位置。
- `qr_future_score` 表示五折排序分数集成后的原始排序分数。
- `retrieval_score` 表示 Dense 第一阶段的相似度分数。

因此，某个候选的 `candidate_rank` 可能与最终 `rank` 不同。这是重排流程的正常表现。

## 3. 分数解释限制

必须遵守以下规则：

### 3.1 原始排序分数不是概率

`qr_future_score` 是用于候选排序的原始分数，不是：

- 用户未来心理状态的概率。
- 模型置信度。
- 用户心理痛苦程度。
- 临床风险等级。
- 候选回复质量百分比。
- 候选回复有效或安全的概率。

不得根据该分数推断用户的未来心理状态。

### 3.2 不要孤立解释分数正负

分数更负不代表检索失败。原始分数的绝对数值不应被直接赋予临床或心理学含义。

如需分析分数，应限制在相同模型、相同评分设置和可比实验条件内。

### 3.3 不同模式的分数不能直接横向比较

Dense、ORCA 和 QR-Future 使用不同的检索或排序计算方式。不能把三个模式的分数当作同一量纲、经过统一校准的概率或置信度。

模式对比应重点查看：

- 返回候选是否相同。
- 候选最终排序如何变化。
- QR-Future 是否将部分初始候选提升或降低。
- 在有明确评测依据时，再结合对应实验指标分析效果。

单次查询的结果不能替代系统级评测。

## 4. 候选回复的使用边界

检索返回的是语料中的候选回复，不是针对当前用户自动生成的最终答案。

因此：

- 高排名不等于临床验证。
- 高排名不等于对当前用户必然适用。
- 候选文本不构成诊断、治疗方案或安全性保证。
- 不得把候选中的陈述直接当作对当前用户事实的判断。
- 引用候选时保留原文，并明确标注其来自检索结果。
- 如果后续 Agent 对候选进行改写或生成，应明确区分原始候选和生成内容。

## 5. 错误状态与空结果

当工具返回 `status="error"` 时，该次调用是业务失败，不能解释为成功检索但没有找到候选。

处理方式：

1. 不展示虚构的结果。
2. 适当时调用 `longpsych_retrieval_health` 检查服务。
3. 服务仍不可用时，明确说明检索暂时不可用。
4. 不得在用户未同意的情况下把 QR-Future 请求静默替换为其他模式。

如果工具成功但候选列表为空，应如实报告空结果，不要补造候选。

## 6. 推荐展示方式

展示候选时，建议包含：

- 最终名次 `rank`。
- 原始回复标识 `response_uid`（仅在需要追踪时展示）。
- 原始候选文本 `response_text`。
- 必要时展示 `candidate_rank` 和 `qr_future_score`，并附上准确解释。

面向普通用户时，不必默认展示内部 `faiss_row` 或所有原始分数；面向调试或研究人员时，可以在说明字段含义后展示。


## 检索结果解释边界（v1.2.1）

1. 不得直接比较 Dense、ORCA、QR-Future 不同检索模式的原始分数大小。
2. retrieval_score 和 qr_future_score 均为排序相关分数，不代表概率、置信度或临床指标。
3. 不得仅凭分数大小断言某种检索模式具有更强的语义理解能力。
4. 比较不同检索模式时，应重点分析候选内容、排序差异及候选集合重叠情况。
5. 对检索结果进行解释时，必须区分直接相关、部分相关和弱相关候选。
6. 不得根据候选回复反向推断用户没有明确表达的个人经历。
7. 如果候选回复出现实习、求职、恋爱等未经用户确认的具体背景，应明确指出其可能存在情境偏差。
8. 不得为了使检索结果显得合理而强行解释弱相关候选。
9. 检索结果是候选回复，不代表系统已经完成心理诊断或确定用户真实心理状态。
